# Процесс обработки

```mermaid
flowchart TD
    A[PDF] --> B[Рендер первой страницы]
    B --> C[Варианты изображения и OCR]
    C --> D[Кандидаты ФИО и номера]
    D --> E{Проверка оператором}
    E -->|Подтверждено| F[Копия в ready]
    E -->|Пропущено| G[Копия в problems]
    F --> H[Локальный план mock robot]
```

В рабочем OCR Studio предусмотрены дополнительные шаблоны, проверка уверенности, пакетный интерфейс и робот внесения. Демо показывает публично воспроизводимый путь без рабочих URL, документов, реквизитов и сетевого внесения.
