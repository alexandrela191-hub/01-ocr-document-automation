# OCR Studio — демонстрационная версия

Портфолио Александра: обработка PDF, OCR полей, проверка человеком, безопасное переименование и подготовка очереди для RPA. Этот репозиторий содержит самостоятельный пример основных этапов, созданный по мотивам OCR Studio v43.17.49. Это **не** производственная версия и не интеграция с рабочим порталом.

## Что демонстрирует проект

1. Первая страница PDF преобразуется в изображение (Poppler, 300 DPI).
2. Tesseract распознаёт текст на исходном изображении и варианте с автоконтрастом; выбирается результат с большей средней уверенностью.
3. Кандидаты на ФИО и номер помещения извлекаются отдельно. Для номера учитывается строка таблицы «Вид помещения | Номер помещения | Площадь | Доля».
4. Оператор проверяет оба поля и подтверждает их. Неподтверждённые документы попадают в `problems/` как копии, исходный файл сохраняется.
5. Подтверждённая копия записывается в `ready/` как `ФИО (номер).pdf`. Совпадающие имена получают суффикс, существующие файлы не перезаписываются.
6. Команда `mock-robot` формирует локальный JSON-план действий; сетевых запросов и входа в портал нет.

Полная рабочая система также включает интерфейс Tkinter, сохранение шаблонов, обработку партий и Selenium-робота. Их код и конфигурация сюда не включены: они связаны с рабочей средой и документами.

## Запуск (Windows)

Установите Python 3.10+, Tesseract OCR с русским языком и Poppler; добавьте `tesseract.exe` и `pdftoppm.exe` в `PATH`.

```powershell
py -m venv .venv
.venv\Scripts\Activate.ps1
pip install -r requirements.txt
python -m ocr_showcase process C:\путь\к\сканам
python -m ocr_showcase mock-robot ready
python -m unittest discover -s tests -v
```

При обработке программа показывает предложения OCR и ждёт подтверждения или исправления. Перед запуском на собственных документах убедитесь, что права на их обработку у вас есть. `ready/`, `problems/`, `source/`, PDF, JSON и изображения игнорируются Git.

## Стек

Python, Tesseract OCR (`rus+eng`), Poppler, Pillow, pdf2image. Рабочая версия дополнительно использует OpenCV, EasyOCR, Tkinter и Selenium.

## Ограничения демо

Эвристики демонстрационной версии зависят от качества скана и макета. Они не обещают точность производственной системы; автоматического внесения данных и подключения к ведомственным ресурсам нет. Файлы с реальными персональными данными в репозиторий не добавляются.
